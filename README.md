# Kima Adventure — downloads

Este repositório só distribui o jogo. Os builds ficam em [Releases](https://github.com/bellizzileandro/kima-adventure/releases), um por versão:

- Windows: `KimaAdventure.exe`
- Android: `KimaAdventure.apk`

O jogo consulta o release mais novo ao abrir e oferece a atualização.
