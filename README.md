# Kima Adventure — downloads

Página: https://bellizzileandro.github.io/kima-adventure/

Este repositório só distribui o jogo:

- Os builds para Windows (`KimaAdventure.exe`) e Android (`KimaAdventure.apk`) ficam em [Releases](https://github.com/bellizzileandro/kima-adventure/releases), um por versão.
- O arquivo `latest.json` aponta para a versão mais nova.
- O jogo lê esse arquivo ao abrir e oferece a atualização.

As releases são publicadas pelo `tools/release.sh` do projeto do jogo.
